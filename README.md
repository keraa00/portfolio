# Kerim Smajlovic — Portfolio

Personal portfolio website built to showcase my work, skills, and experience as a Full-Stack Developer.

**Live site:** [kerimsmajlovic.dev](https://kerimsmajlovic.dev)

---

## About

A clean, modern portfolio with a focus on performance and aesthetics. Features a liquid glass navigation system, smooth section transitions, and a responsive layout built for all screen sizes.

## Tech Stack

- **Framework** — Next.js 16 (App Router)
- **Language** — TypeScript
- **Styling** — Tailwind CSS v4
- **Icons** — Lucide React, React Icons
- **Deployment** — Vercel

## Features

- Liquid glass pill navigation — desktop (top) and mobile (bottom)
- Active section tracking with smooth sliding indicator
- Directional glow effect on hover
- Fully responsive across all screen sizes
- Optimized images with Next.js `<Image />`

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.
